# 拼多多案例分析 2026（公司金融）

- `计算.py`：题面全部数据与第一至五题的计算，输出到 `结果/`
- `计算_对标.py`：第四题（2）与京东的对照（京东数据来自其 2025 年度 Form 20-F 年报，SEC 编号 0001193125-26-157870）
- `生成报告.py` + `报告模板.md` → `报告.qmd` → `报告.docx`、`报告.pdf`
- `结果/`：各题结果表和图，命名与题号对齐（01 现金流量表、02 共同比与盈利、03 利润与现金、04 财务比率、05 预测）

运行：`conda run -n ml python 计算.py && conda run -n ml python 计算_对标.py && conda run -n ml python 生成报告.py && quarto render 报告.qmd`

## 口径假设（写报告时已在正文说明）
- EBIT = 营业利润 + 非经营损益净额（沿用课件利润表结构）
- 购建支出 = 固定资产及无形资产净额变动 + 折旧摊销 + 题面修正额
- 现金余额含受限现金；FCFF 的经营性流动资产含受限现金（按题面）
- 京东：销售费用 = 履约费用 + 营销费用；权益取合计权益
